# 🤖 Telegram-бот АРКАИМ VPN

Полностью готовый асинхронный Telegram-бот на Python (`aiogram 3` + `SQLite`) для продажи подписок, выгрузки VLESS-ключей, инструкций и клиентской поддержки.

---

### 🚀 Как запустить бота за 3 шага:

#### Шаг 1. Получите токен бота у @BotFather
1. Откройте Telegram и найдите бота **[@BotFather](https://t.me/BotFather)**.
2. Отправьте команду `/newbot`.
3. Введите название вашего бота (например, `АРКАИМ VPN`).
4. Введите юзернейм бота (например, `arkaim_vpn_robot`).
5. Скопируйте полученный **HTTP API Token** (например, `7123456789:ABCdefGhIJKlmNoPQrsTUVwxyZ`).

---

#### Шаг 2. Вставьте токен в файл `config.py`
Откройте файл `bot/config.py` и вставьте ваш токен:

```python
BOT_TOKEN = "7123456789:ABCdefGhIJKlmNoPQrsTUVwxyZ"
```

---

#### Шаг 3. Запустите бота
Запустите бота командой из корня проекта:

```bash
python bot/main.py
```

После этого откройте вашего бота в Telegram и нажмите **`/start`**! 🎉

---

### 🛠️ Возможности бота:
- 🛡️ **Мой профиль / Ключ**: Показывает остаток дней подписки, активный `vless://` ключ и копирование в 1 клик.
- 💳 **Купить VPN / Продлить**: Тарифы («Разведчик» 1 мес, «Страж» 6 мес, «Вождь» 12 мес) с выбором способов оплаты (СБП, Т-Пэй, Крипта, Telegram Stars).
- 📲 **Инструкции по настройке**: Пошаговые интерактивные руководства для iOS, Android, Windows, macOS со ссылками на приложения.
- ⚡ **Статус серверов**: Информация об аптайме и пинге узлов сети (Москва, Франкфурт, Амстердам, Хельсинки).
- ❓ **FAQ и Поддержка**: Отвечает на вопросы и связывает с администратором.
